# Process Mining Project

This repository contains the code, data, and results for a Process Mining project applied to hospital billing logs.

## Summary
- **Description:** process analysis and process mining algorithms on XES event logs.
- **Language:** Python
- **Data:** [Dataset/HospitalBilling.xes](Dataset/HospitalBilling.xes)

## Repository Structure
- [Code/](Code/) — source code and dependencies
	- [Code/requirements.txt](Code/requirements.txt)
	- [Code/Algorithms/algorithms.py](Code/Algorithms/algorithms.py)
	- [Code/Analysis/analysis.py](Code/Analysis/analysis.py)
    - [Code/Dataset/HospitalBilling.xes](Dataset/) — event logs in XES format
- [Results/](Results/) — outputs produced by the scripts (plots, tables, models)
- [Report/](Report/) — project reports and documentation
- [LICENSE](LICENSE)

## Goal
The goal is to explore and apply process mining techniques to the provided hospital billing event log, perform process analysis, extract models, and produce reproducible results.

## Requirements
Create a virtual environment.

Example (Windows PowerShell):

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r Code/requirements.txt
```

If `Code/requirements.txt` is not up-to-date, install the required packages manually.

## Running the code
Main scripts are located in `Code/Algorithms` and `Code/Analysis`.

- Run the main analysis:

```bash
python Code/Analysis/analysis.py
```

- Run mining/extraction algorithms (outputs will be written to `Results/`):

```bash
python Code/Algorithms/algorithms.py
```

## Results
Outputs generated by the scripts (plots, metrics, models) are saved in `Results/`.
